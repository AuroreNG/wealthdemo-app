# WEALTHDEMO

Financial assessment and visualization application using the emerald, gold, and white WEALTHDEMO identity.

## Simple GitHub Pages structure

- `index.html` — application structure
- `tokens.css` — brand colors and design tokens
- `app.css` — responsive application styling
- `app.js` — calculations, interactions, and PDF report
- `wealthdemo-logo.webp` — transparent optimized logo

## Preview

Serve this directory with any static web server. For example:

```bash
npx serve .
```

## GitHub Pages

Upload all files to the repository root. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
